### The Challenge
The school lacked reliable internet access, so a standard cloud-based LMS wasn't viable. The project needed a full-stack learning management system that could run entirely offline over a local network, while still giving teachers modern conveniences like real-time grade updates and secure, role-based access.

### Approach
- Developed a full-stack LMS with **authentication and role-based access control (RBAC)**, ensuring teachers, students, and administrators each had appropriate permissions.
- Built an interactive **gradebook** and designed the entire system to run **offline over a local network**, removing dependence on internet connectivity.
- Implemented and optimized **RESTful APIs** with Express.js and MongoDB for grade storage and retrieval, and integrated **WebSockets** for real-time classroom updates.
- Built **CSV import/export** functionality to make the system compatible with teachers' existing workflows.
- Debugged frontend and backend issues, API failures, and UI inconsistencies while collaborating with a multidisciplinary team using **Git, Agile methodologies, and architecture decision records (ADRs)**.

### Results
- Delivered a functioning offline-first LMS tailored to a real-world, low-connectivity environment.
- Enabled real-time gradebook updates for teachers via WebSocket integration.
- Supported data portability for teachers through CSV import/export tooling.

### Key Achievements
-  Built a fully offline-capable LMS for a real school with limited internet infrastructure
-  Implemented secure authentication and role-based access control
-  Delivered real-time classroom updates via WebSockets alongside a REST API backend
