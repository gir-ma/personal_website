### The Challenge
RT-LAMP (reverse transcription loop-mediated isothermal amplification) is a molecular diagnostic technique used for rapid, low-cost testing, but designing effective primers for it is technically demanding and inaccessible to non-experts. The goal of this research project was to make RT-LAMP primer design more accessible by combining computational primer-design algorithms with a user-friendly web platform.

### Approach
- Researched existing RT-LAMP primer design methods and proposed a new, more accessible tool combining computational algorithms with a web interface.
- Designed and implemented a computational algorithm to automate primer placement and detect problematic secondary structures (hairpins) that can reduce primer effectiveness.
- Built accuracy testing into the pipeline to validate primer placement quality.
- Incorporated user feedback throughout development to improve the tool's usability for non-expert users in molecular diagnostics.

### Results
- Delivered a working proposal and prototype for a primer design and hairpin detection tool aimed at improving accessibility in molecular diagnostics research.
- Contributed to an ongoing multi-year research effort as part of a selective, team-based research apprenticeship (ERSP).

### Key Achievements
-  Designed a computational algorithm for automated RT-LAMP primer placement and hairpin detection
-  Combined algorithm design with a web platform to make molecular diagnostics tooling more accessible
