# gir-ma.github.io

Personal portfolio site for Girma Terfa, built with Jekyll and the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) remote theme. Hosted via GitHub Pages.

- Home, Projects, CV, and Contact pages live in `_pages/`.
- Portfolio projects are a custom collection in `_projects/`.
- Site-wide settings (nav, author info, plugins) are in `_config.yml`.

## Local development

```bash
export PATH="/opt/homebrew/opt/ruby@3.3/bin:$PATH"
bundle _2.5.22_ exec jekyll serve --no-watch --port 4001
```

Then open `http://127.0.0.1:4001/`.
